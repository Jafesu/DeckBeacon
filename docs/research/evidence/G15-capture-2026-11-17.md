# G15 hardware capture: Tier-1 non-Valve reference unit

- **Device:** Dell G15 5520 running SteamOS 3.9.5 (holo, `rel` branch)
- **Captured:** 2026-11-16 local date on the device. The filename uses 2026-11-17 because the cloud session asked for that name.
- **Captured by:** the local Claude Code session, at the cloud session's request. Read-only: no sudo, installs, systemctl/loginctl changes or power actions, and Steam was not started or stopped.
- **Mode at capture:** **Desktop Mode** (KDE Plasma on Wayland: `kwin_wayland` and `plasmashell` running, no `gamescope` process). Steam client was running. No game was running.
- **Redactions:** the username is replaced with `<user>` (home is `/home/<user>`). The battery model name and serial number are redacted. No hostname, IP, MAC, SSID, Steam account name or SteamID appeared in the output that was kept. Steam credential files were not opened.

Each command appears in a code block, followed by its output exactly as printed, apart from those redactions.
