# Managed updates and releases
Agent updates detected automatically but require explicit user approval from HA or Decky. Never unattended by default. Stable/beta/development channels per device; independent agent, HA, Decky and dashboard versions, versioned shared protocol. Release artifacts published from monorepo, signed and checksummed, with SBOM where feasible. Agent stages download, validates signature/compatibility/disk, waits for idle/safe window, switches atomic active/previous slots through independent updater, health-checks and rolls back if failed. If asleep/offline, approved update remains pending; do not wake device solely to update. Show update history and errors.

HA integration updates via HACS and normal HA lifecycle; Decky plugin updates via supported Decky mechanism; frontend separately via HACS frontend distribution. Agent must not silently overwrite those components. CI: lint, tests, protocol compatibility, security/dependency scanning, builds, packaging, signed releases, release qualification and rollback tests.
