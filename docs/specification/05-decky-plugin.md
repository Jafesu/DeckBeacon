# Decky plugin
Optional Gaming Mode companion built with TypeScript/React and supported Decky plugin interfaces. Screens: Overview, Pairing, Connection, Notifications, Games/Downloads, Agent Updates, Permissions, Diagnostics. Interact with local agent via narrow authenticated IPC, not unrestricted network or root calls. Support pairing approval and notification action responses. If Decky unavailable, agent + HA core remains functional. Verify supported Gaming Mode toast/interactive capabilities experimentally; use plugin notification center when system toast actions unavailable. Respect plugin loader packaging and update lifecycle.
