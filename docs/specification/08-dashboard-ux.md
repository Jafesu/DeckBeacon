# Dashboard UX
Native HA entities and optional custom Lovelace cards. Cards: device, currently playing, downloads, game library, performance, management. Optional preconfigured multi-device dashboard. Custom frontend TypeScript; cards use HA integration, not agent direct. Visual card editor and YAML config. Mobile responsive, keyboard/screen reader accessible, theme aware, lazy-load artwork, no unbounded polling. Explain unavailable vs unsupported vs disabled vs unknown. Confirmation for destructive commands and force actions. Authenticated artwork proxy; no exposed agent file URLs. Dashboard and cards versioned independently; integration works without frontend.
