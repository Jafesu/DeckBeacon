# DeckBeacon brand guide

## Concept
A radiant diamond beacon, two symmetrical transmission arcs, and a grounded antenna stem. No borrowed platform symbols.

## Colors
- Deep navy: `#101B2C` — primary dark background
- Beacon teal: `#24D6C5` — primary accent
- Signal blue: `#388CFF` — secondary accent
- Ink: `#15243A` — light UI text
- Off-white: `#F4FAFF` — dark UI text
- Muted slate: `#74879B` — neutral supporting text

## Typography
- Preferred: **Manrope**, weight 800 for wordmark, 400–700 for UI.
- Fallback: Inter, then system sans-serif.
- SVG wordmarks contain editable text and require the font for exact rendering. Convert text to paths in your vector editor when preparing final production artwork if necessary.

## Usage
- `masters/deckbeacon-icon.svg`: transparent full-color mark.
- `masters/deckbeacon-icon-monochrome.svg`: black single-color mark; recolor all fills and strokes as one color.
- `masters/deckbeacon-logo-light.svg`: for light backgrounds.
- `masters/deckbeacon-logo-dark.svg`: for dark backgrounds.
- `png/`: transparent PNG masters, HA exports, previews, placeholders and avatars.
- `extras/`: vector banners, social previews, neutral artwork placeholders.
- The mark is designed to be recognizable at small sizes; test final rendering at 16–24 px in actual target UI.
- Do not stretch or alter the aspect ratio.
- Home Assistant asset naming and Decky marketplace sizes should be verified at packaging time.
